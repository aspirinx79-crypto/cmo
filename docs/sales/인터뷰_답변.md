# 영업의 본질 교육자료 — 인터뷰 답변 정리

## 1. 강사 정보
- 이름/직함: 이인선 상무이사
- 회사: (주)상생어벤져스 (먹스타는 상생어벤져스컴퍼니의 자회사, 이인선 = (주)먹스타 대표)
- 인스타그램: taste_goyang
- 연락처: PPT 마지막 장에만 표기 (이 메모에는 적지 않음)

## 2. 판매 상품 (출처: mukstar.co.kr)
- 교육자료에는 상품 종류만 소개, 가격은 넣지 않음
- 주력: **CMO 서비스** — 식당 예산(예: 월 150만~300만 원)에 맞춰 매달 마케팅을 기획·실행하는 통합 대행, **월 단위 계약** 강조
  - 한 팀이 플레이스·검색광고·체험단·인스타그램 등 전 채널 담당, 단톡방 소통, 매주 결과보고서, 매월 다음 달 기획
  - 매출·순위는 보증하지 않음 — 잘 된 건 이어가고 안 된 건 바꾼다
- 그 밖의 상품: 먹스타 PPL(인플루언서), VIP 파워블로그, 먹스타 기자단(숏폼 배포), 외국인 체험단, 숏폼채널 제작, 먹스타파티(인플루언서 단체 방문), 프랜차이즈 마케팅(가맹 DB), 브랜딩 영상, IPTV 광고, 숏폼 클래스, 지원사업·바우처, 맛집 홈페이지 제작
- 신뢰 요소: 직영 매장 운영(중화객잔수 강남구청점, 미친양꼬치 잠실점, 케이찹사라다 신사직영점), 외식업 브랜드 1,000곳, 크리에이터 800명, 누적 조회수 2.5억

## 3. 영업 수수료 구조 (교육에서 설명)
- 우리가 100% 직접 시행하는 상품 → 마진 높음(거의 100%)
- 외주를 주는 상품 → 마진 낮음
- 영업자 수수료: 구체적 %는 넣지 않음 — "직접 시행 상품이 수수료가 더 높다" 수준으로만 설명

## 4. 다니는 모임 (공식 명칭)
- 서울과학기술대학교 최고위건축개발과정 (CADO, 카도) — 매주 목요일
- 중앙대학교 강남 외식산업 최고위과정 (강사 확인)
- BNI 조찬 모임 — 매주 목요일 아침
- CBMC 기독실업인회 — 격주

## 5. 첫 고객과 기억에 남는 사례
- 제대 후 첫 영업: 인스타그램(맛고양 채널)으로 시작 — "우리 매장도 홍보해 달라"는 요청에서 첫 계약
- 고객 유입 1위: **지인 소개** — 마케팅 서비스에 만족한 고객이 소개해 줌
- 사례 ① 강화도 「바다향기」 (최근)
  - 카도 워크숍으로 강화도에 갔다가 식당 방문 → 영수증을 받아 직접 영수증 리뷰 작성
  - 그 리뷰가 영수증 리뷰 1등으로 올라간 것을 사장님께 보여 드리고 "마케팅 궁금한 거 있으면 연락 주세요"
  - 나중에 사장님이 먼저 전화 → CMO 계약
  - 참고자료: 강사가 작성한 영수증 리뷰 사진 (받을 예정)
- 사례 ② 여주 「엄마네」, 「큰집한우」
  - 마케팅 후 매출이 계속 오르고 있어 약 2년째 계약 유지 중

## 6. 첫 만남 진행 순서 (강사 실제 방식)
1. **방문 전 사전 조사**: 네이버 플레이스 순위, 리뷰, 플레이스 전반적인 분위기, 홈페이지 유무, 네이버 뉴스(언론 기사) 노출 여부
2. **고민 묻기**: "마케팅에서 고민되시는 게 있으세요?"
3. **회사 소개**: 우리는 요식업 마케팅 전문가
4. **주력 제안**: 그중 가장 잘하는 것 = 마케팅 직원처럼 일해 주는 CMO 서비스 — 첫 만남에 바로 소개
5. **계약**: 되면 그 자리에서, 안 되면 다음 만남에서 계약
