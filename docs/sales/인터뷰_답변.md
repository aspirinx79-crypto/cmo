# 영업의 본질 교육자료 — 인터뷰 답변 정리

## 1. 강사 정보
- 이름/직함: 이인선 상무이사
- 회사: (주)상생어벤져스 (먹스타는 상생어벤져스컴퍼니의 자회사, 이인선 = (주)먹스타 대표)
- 인스타그램: taste_goyang
- 연락처: PPT 마지막 장에만 표기 (이 메모에는 적지 않음)

## 2. 판매 상품 (출처: mukstar.co.kr)
- 교육자료에는 상품 종류만 소개, 가격은 넣지 않음
- 주력: **CMO 서비스** — 식당 예산(예: 월 150만~300만 원)에 맞춰 매달 마케팅을 기획·실행하는 통합 대행, **월 단위 계약** 강조
  - 한 팀이 플레이스·검색광고·체험단·인스타그램 등 전 채널 담당, 단톡방 소통, 매주 결과보고서, 매월 다음 달 기획
  - 매출·순위는 보증하지 않음 — 잘 된 건 이어가고 안 된 건 바꾼다
- 그 밖의 상품: 먹스타 PPL(인플루언서), VIP 파워블로그, 먹스타 기자단(숏폼 배포), 외국인 체험단, 숏폼채널 제작, 먹스타파티(인플루언서 단체 방문), 프랜차이즈 마케팅(가맹 DB), 브랜딩 영상, IPTV 광고, 숏폼 클래스, 지원사업·바우처, 맛집 홈페이지 제작
- 신뢰 요소: 직영 매장 운영(중화객잔수 강남구청점, 미친양꼬치 잠실점, 케이찹사라다 신사직영점), 외식업 브랜드 1,000곳, 크리에이터 800명, 누적 조회수 2.5억

## 3. 영업 수수료 구조 (교육에서 설명)
- 우리가 100% 직접 시행하는 상품 → 마진 높음(거의 100%)
- 외주를 주는 상품 → 마진 낮음
