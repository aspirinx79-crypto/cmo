## 한 줄

**「직원 한 명 더 뽑는 대신, 마케팅 담당자를 붙입니다.」**

사업장이 노출되는 모든 온라인 채널을 상주 관리한다. 원장·대표는 단톡방에
말만 남기면 담당자가 전 채널에 반영하고 완료 보고까지 한다.

월 30만 원은 **주 1회 아르바이트 인건비 수준이지만 실무는 마케팅 담당자
1인분**이다 — 이 대비가 제안서 전체의 축이다.

## 대상과 값

| | |
|---|---|
| 대상 | 학원 · 병원 · 외식업 등 **지역 기반 사업장** |
| 채널 | 네이버 · 카카오맵 · 구글 · 업종별 전문 플랫폼 |
| 금액 | **월 300,000원 / 1개 지점 · VAT 별도** |
| 지점 추가 | 지점당 단가 별도 협의 |

## 1. 네이버 플레이스 관리 — 핵심 채널

| 관리 항목 | 주기 |
|---|---|
| 새소식 게시 — 플레이스 노출 가산점 확보용 | **주 1회 정기** |
| 연휴·명절·방학·휴진 등 운영 일정 공지 | 수시 |
| 네이버 정책·알고리즘 업데이트 안내 및 즉시 적용 | 업데이트 발생 시 |
| 대표키워드 변경 / 상세설명 최적화 | 분기 1회 + 필요 시 |
| 가격·항목 변경, 전화번호·운영시간·사진 교체 | 요청 시 당일~익일 |
| 악성 리뷰 대응 | 발생 즉시 |

## 2. 업종별 정보 변경 적용 범위

요청하면 **전 채널에 일괄 반영**된다.

| 업종 | 주요 변경 관리 항목 |
|---|---|
| 학원 | 과목·강좌 구성, 수강료, 개강·모집 일정, 시간표, 강사진, 설명회 공지, 방학특강 안내 |
| 병원·의원 | 진료과목, 진료시간, 휴진·대체공휴일 안내, 의료진 정보, 예약 안내, 주차·오시는 길 |
| 외식업 | 메뉴 구성, 가격 인상, 영업시간, 휴무일, 대표사진, 예약·포장 안내 |

## 3. 카카오맵 · 구글 비즈니스 프로필 관리

- 악성 리뷰 모니터링 및 대응 (양 채널 공통)
- 운영 정보·가격·전화번호·운영시간·사진 등 변경 대행
- **리뷰 유입 캠페인 월 2건** — 실이용 고객 대상 리뷰 요청 이벤트 기획·운영

> **의료기관 제외.** 「의료법」 제27조(환자 유인·알선 금지) 저촉 우려로
> 병원·의원에는 리뷰 유입 캠페인을 제공하지 않는다.

외국인 이용 비중이 있는 사업장은 구글 노출이 실매출로 직결된다.

## 4. 업종별 전문 플랫폼 · 내비게이션 관리

- 학원 — 학원 정보 플랫폼, 지역 커뮤니티 노출 정보 관리
- 병원·의원 — 병원 검색·예약 플랫폼 등록 정보 관리
- 외식업 — 맛집 플랫폼 등록 정보 관리
- 내비게이션 등록 정보 및 **잘못된 정보 정정** (폐업 표기, 구 전화번호·주소 등)

## 5. 악성 리뷰 대응 프로세스 — 전 채널 공통

접수 → 유형 판단 → 채널별 최적 대응 루트 선택. **판단 자체를 대신한다.**

| 리뷰 유형 | 대응 방식 |
|---|---|
| 명예훼손·욕설·허위사실 / 경쟁업체 의심 리뷰 | 네이버 — 신고센터 접수 대행 / 기타 매체 — 다량 신고 처리 |
| 실제 불만 또는 오해 소지가 있는 리뷰 | 답글 대응 — 사과 + 개선 의지 + 재방문 유도 문안 작성 |
| 단순 별점 테러 | 모니터링 후 긍정 리뷰 유입으로 희석 |

**이 항목이 중요한 이유** — 사업장 이미지를 가장 크게 훼손하는 것은 악플
자체가 아니라 **업무 종료 후 감정이 상한 상태에서 직접 단 답글**이다. 대응
판단과 문안 작성을 맡기면 그 위험이 사라진다. 특히 학원·병원은 답글 한 줄이
학부모·환자 커뮤니티로 그대로 퍼진다.

## 6. 월간 리포트 & 전략 제안

- 플레이스 통계 리포트 공유 — 조회수 / 유입 키워드 / 저장수 / 길찾기·전화 클릭수
- 데이터 기반 익월 실행 전략 제안
- 동일 상권 경쟁 사업장 대비 노출 순위 모니터링

## 7. 마케팅 전략 브레인스토밍

- 학원 — 모집 시즌 전략, 설명회 홍보, 신규 강좌 포지셔닝
- 병원·의원 — 시즌 진료 수요 대응, 신규 진료과목 안내 전략
- 외식업 — 시즌 프로모션, 신메뉴 구상
- 단톡방 상시 소통 — 별도 회의 일정 조율 없이 바로 문의 가능

## 8. 소통 방식 — 전용 단톡방 1개로 끝난다

「이번 달부터 수강료 조정됐어요」 한 줄만 남기면 담당자가 네이버·카카오·구글·
전문 플랫폼 전 채널에 반영 후 완료 보고를 한다.

**응답 기준** — 평일 운영시간 내 접수 시 당일 확인 / 24시간 내 처리 완료

## 9. 서비스 금액

**온라인 채널 통합관리 — 월 300,000원 / 1개 지점 · 부가세 별도**

포함되는 것 여덟 가지:

1. 네이버 플레이스 관리 (주 1회 새소식 포함)
2. 카카오맵 · 구글 비즈니스 프로필 관리
3. 업종별 전문 플랫폼 · 내비게이션 관리
4. 리뷰 유입 캠페인 월 2건 (의료기관 제외)
5. 전 채널 악성 리뷰 대응
6. 운영 정보 변경 상시 대행
7. 월간 통계 리포트 및 전략 제안
8. 마케팅 전략 상시 상담

2개 지점 이상 계약 시 지점당 단가를 별도 협의한다.

## 10. 계약 조건 및 안내 사항

| 항목 | 내용 |
|---|---|
| 계약 단위 | 1개 지점 기준 월 정액. 지점 추가 시 별도 산정 |
| **광고비 별도** | 네이버 검색광고·플레이스 광고 등 **매체 집행비는 대행 수수료에 포함되지 않고 실비로 별도 청구** |
| **별도 견적 항목** | 전문 사진 촬영, 영상 제작, 상세페이지 디자인, 홈페이지 제작은 **범위 밖** |
| 업종별 법규 준수 | 의료기관 — 「의료법」상 의료광고 규정 및 사전심의 대상 여부 / 학원 — 「학원법」상 과대·허위광고 금지. **사전심의 신청 및 수수료는 사업장 부담** |
| 리뷰 신고 | 각 플랫폼 정책에 따른 접수 대행이며 **최종 삭제 결정을 보증하지 않는다** |
| 계정 권한 | 네이버 스마트플레이스·카카오맵·구글 비즈니스 프로필의 **관리자 또는 매니저 권한 위임 필요** |
| 계약 기간 | 월 단위 자동 연장. 해지 시 **차월 시작 30일 전까지** 서면 또는 유선 통보 |
| **성과** | 플랫폼 알고리즘은 운영사 정책에 따라 수시 변동되므로 **특정 순위나 매출 상승을 보증하지 않는다.** 보증하는 것은 **관리 실행과 최적화** |
| 정보 제공 협조 | 수강료·진료시간·가격 등 변경 사항은 사업장 측이 단톡방으로 전달해야 반영 가능 |

## 11. 이 서비스가 필요한 이유

| 직접 관리하실 경우 | 통합관리 대행 이용 시 |
|---|---|
| 채널이 4개 이상으로 분산 — 어디에 무엇이 등록됐는지 파악조차 어려움 | 담당자가 전 채널 현황을 통합 관리, 변경 사항 누락 없음 |
| 플레이스 새소식은 알면서도 바빠서 몇 달째 방치 | 주 1회 정기 게시로 노출 가산점 꾸준히 확보 |
| 악플이 달려도 대응 방법을 몰라 방치하거나 감정적으로 답글 | 유형별 판단 후 신고 접수 또는 전략적 답글로 대응 |
| 모집 시즌·성수기가 지나서야 홍보를 준비 | 시즌 일정에 맞춰 사전 콘텐츠 및 노출 준비 |
| 네이버 정책이 바뀐 줄도 모르고 지나감 | 업데이트 발생 시 즉시 안내 및 적용 |
| **직원 채용 시 월 200만 원 이상 고정비** | **월 30만 원으로 마케팅 담당자 1인분** |

## 카탈로그와 다른 점

`cmo/data/products.json` 의 `네이버-서비스툴관리` 와 대조한 결과다.

| | 카탈로그 | 이 제안서 |
|---|---|---|
| 정가 | 300,000 | 같음 ✅ |
| 업종 | **외식업만** 쓰여 있음 | **학원·병원·외식업 셋** |
| 리뷰 유입 캠페인 | 「카카오맵 리뷰 작업 월 2건」 | **카카오맵·구글 양 채널 월 2건, 의료기관 제외** |
| 법규 | 없음 | 의료법 제27조·의료광고 심의·학원법 |
| 계약 조건 | 없음 | 해지 30일 전 통보, 권한 위임, 성과 미보증 |

**카탈로그 고지사항이 낡았다.** 업종 확장과 법규 항목이 반영돼 있지 않다.
고쳐야 할 값은 `cmo/data/_source/products.tsv` 와 `overrides.json` 에 있다 —
`products.json` 은 만들어지는 파일이라 직접 고치면 다음 반입 때 덮인다.

## 제안서에 쓸 때

- **월 30만 원 대 월 200만 원** 대비가 가장 강한 문장이다
- **「특정 순위나 매출 상승을 보증하지 않는다」** 는 반드시 남긴다 — 빼면
  구두 약속이 된다
- **광고비 별도**와 **촬영·영상·홈페이지 별도 견적**은 견적서에서 자주 새는
  구멍이다. 계약가에 포함된 것으로 읽히면 안 된다
- 병원·의원 제안서에서 **리뷰 유입 캠페인을 빼야 한다** — 의료법 위반이다
